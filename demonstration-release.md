# Demonstration Release Scope

This version of **Transformer Health Command** is a realistic government control-room demonstration. Its city, zone, transformer, telemetry, alert, ticket, technician, and employee-access records are illustrative interface data intended to demonstrate the monitoring workflow.

The release includes Chennai monitoring for Avadi and Ambattur, and Coimbatore monitoring for R.S. Puram, Peelamedu, and Singanallur. It uses calibrated OpenStreetMap base layers with interactive zone boundaries, coverage rings, and transformer points.

Live SCADA or MQTT ingestion, database-backed ticket writes, production employee assignment enforcement, and administrator-approved official source assets are intentionally deferred. The database model and access scaffolding remain available for a later operational integration.
